# SIEM Lab Completion Report

## Executive Summary

A SOC-style SIEM environment was designed and validated with controlled simulated endpoint activity. The project focused on telemetry collection, custom detections, alert triage, hunting, correlation, and incident documentation.

## Scope

- Authentication monitoring
- Process/script monitoring
- Account and privilege changes
- Persistence indicators
- Audit/defense-evasion indicators

## Outcome

All eight planned detection scenarios produced the expected simulated detection result.

## Skills Demonstrated

SIEM concepts, log analysis, detection engineering, event correlation, alert triage, threat hunting, incident response, detection tuning, telemetry normalization, and Git/GitHub documentation.
